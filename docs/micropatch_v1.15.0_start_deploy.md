# v1.15.0 — Старт с раскладкой: здания + 10% пула карт

## Что изменилось
Забег теперь начинается с РАЗЛОЖЕННЫМ полем:

- **Все здания** из колоды выходят на поле целиком (здания НЕ входят в проценты).
- **10% пула карт** (округление вниз) — тоже сразу на поле, в порядке колоды.
- Раскладка идёт **спиралью от центра** поля, только по доступным клеткам
  (маска playableMask); в центре уже стоит базовое здание фракции
  («Подготовленная земля»), раскладка его обходит.
- Колода — «барабан»: постановка расходует её как раньше. Застакованная
  запись колоды ставится на поле готовым юнитом ×N (очереди deckStacks —
  те же, что и при ручной постановке).
- Правило распространяется и на Вознесение, и на Рестарт Эпохи.

## Техническое
- `logic/epochs.js`: новый `autoDeployStart()` — структурно повторяет
  ручную постановку (`logic/grid.js onCellClick`), но без sfx/тостов/
  статистики; вызывается в `resetRunCommon` после выдачи колоды и
  контрактов, до `computeIncome`.
- `resetRunCommon(faction, deck, noDeploy)` — третий параметр отключает
  авто-раскладку; обучение (`main.js tutStartRun`) вызывает с `noDeploy`,
  чтобы шаг «поставьте карту» требовал пустое поле.
- Кэш-баст: `index.html` → `epochs.js`, `main.js`, footer `v1.15.0`.
