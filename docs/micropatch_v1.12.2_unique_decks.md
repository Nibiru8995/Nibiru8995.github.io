# МИКРО-ПАТЧ v1.12.2 — «Уникальные особенности»

Дата: 2026-11-04 · База: v1.12.1 (реворк зверей «Дикие угодья»)
Цель: дожать реворк каждой подрасы до самостоятельной колоды — карты внутри
подрасы перестают дублировать друг друга, механики получают честные ниши.
Коммит: репозиторий Nibiru8995/Nibiru8995.github.io (main).

---

## 1. Почему

После реворка v1.12.0 в каждой подрасе зверей (Стая / Стадо / Лес) и в
горячих ветках демонов остались карты с ПОЧТИ ИДЕНТИЧНЫМИ особенностями:
b3≡b19 (падаль по актам), b17≡b37 (кап выпаса + твёрдая дичь), b2≡b28
(удар по стаду), d17≡d18 (тлеющие рядом), d20≡d30 (остужение взрывов).
Игрок не видит разницы — карта не даёт выбора, только имя. Этот патч
разводит дубли и реализует те правила, которые раньше были только текстом.

## 2. Звери (beast)

- **b0 Крыса → «Стайная мелочь»**: хищники в её угодьях берут ТРОФЕЙ ×2 —
  домашняя дичь Стаи (решает «соло-голод»: стая охотится даже без леса).
  Своя старая пассивка (+8% за зверя в общих угодьях, кап +24%) осталась.
- **b5 Токсичный надел** глушит и вольный луг (текст уточнён).
- **b2 Кабан (Щетина)**: вместо «держит удар» — рой у построек:
  +8% за каждое ЗДАНИЕ в своих угодьях (кап +24%). «Держит удар» остаётся
  только у b28 Топтуна.
- **b19 Гиена → «Падаль смеха»**: +10%/акт охоты в рад.2 (кап +40%) КАК РАНЬШЕ
  у b3, но ДОПОЛНИТЕЛЬНО +5% за каждого ДРУГОГО падальщика в общих угодьях —
  «стервятники-компания» (b3 остаётся чистым снайпером актов).
- **b37 Мамонт → «Эпоха»**: стадо в его угодьях — доход ×1.25 (кап выпаса
  снят ТОЛЬКО у b17 Колосса). Твёрдая дичь ×0.5 — у обоих, это рамочная
  механика эпических травоядных.
- **Стадо — вольный луг**: дичь БЕЗ флоры в угодьях получает фикс +12%
  вместо нуля (голод уже не ноль). Глушится Токсичным наделом (b5).

## 3. Демоны (demon)

- **d17 Дымовик**: аура +10%/тлеющего → **+5%** (разнос), а главная сила —
  НОВОЕ: тлеющие (3+ угля) в рад.2 копят угли **×1.2** — «дым раздувает жар».
- **d18 Пепельная Гончая (Чуйка)**: без изменений (+10% за тлеющего СОСЕДА) — теперь
  это «нос» у двери, а d17 — «мех» у топки.
- **d30 Вздох (тамер Мрака)**: остужение соседей — было ×1.15, стало **×1.35**
  («вдох глуше Золовки»): перегрев соседа превращается в тихий бафф ×1.35.
- d20 Зыбь — пепельная аура ×1.08 без изменений (развод с d30 — по зонам).

## 4. Культисты (cultist) — Хор c14–c19

- **c16 Кадилонос** («Хранитель Жара»): каждый Хранитель Жара в его дыму
  (рад.2) хранит ещё +3% заряда — единственный Хор-инженер «сохранения».
- **c17 Стихарь** → «Канон в 900 строк»: +2% к вкладу за КАЖДОГО участника
  ритуала (до +20%). Прежнее «+8% если источник в рад.3» удалено (было
  слабо и слепо) — теперь он кормится размером паствы.
- **c18 Дьячок** → «Правки канона»: каждый ВНЕШНИЙ круг даёт ещё +2% к
  его вкладу. ПРАВИЛО РЕАЛИЗОВАНО ВПЕРВЫЕ (в тексте было, в движке — нет);
  бонус появляется после подсчёта внешних кругов (E.outer).
- c14 Рассветный (+0.05/Певчего в рад.1), c15 Уставный (×1.2 при стака 2+),
  c19 Разнорядный (+6%/здание в рад.2) — ниши оставались уникальными.

## 5. Теофания и Внешние («Сущности»)

- **Внешних (noPlace: c34–c39) РАЗРЕШЕНО класть в колоду** — но НЕ разре-
  шено ставить на грид: они нисходят сами (grid.js блокирует постановку
  noPlace-карт с тостом; Гримуар убирает бывший запрет на добавление).
- Внешние В АКТИВНОЙ КОЛОДЕ культиста усиливают нисхождение: **+2% шанс
  за каждое внешнее в колоде (до +12%)**, потолок шанса поднят 30% → 42%.
- Взвешенный мешок: внешнее из колоды попадает в мешок нисхождения ДВАЖДЫ
  («паства призывает тех, кого держит на помине»).
- Тексты (mechanicDesc / memo / guideTip) в factions.js обновлены;
  в списке колоды у внешних появилась пометка «не ставится — нисходит сам 🌑».
- Хтони c10/c11 остаются обычными картами (ставятся, встают на место Алтаря).

## 6. HUD: виджет композиции подрас

Новая строка над Колодой (левая колонка, #subraceBar): живые счётчики
подрас/ролей на поле (стак считается N живыми) + предупреждающие подсказки:
- ⚠ хищники живут без дичи / стадо без флоры — вольный луг / падальщикам
  нужен охотник (звери);
- 💭 Мраку нужен чужой взрыв / ⚠ Легион ждёт строя (демоны);
- ⚠ вампирам нужны Скованные (нежить);
- ⚠ Ложе накапливает Сомнение — нужен Медиум / 🌑 Внешние в колоде усиливают
  нисхождение (культисты).
Перерисовка — по сигнатуре, только при изменениях (кэш HUD, 5 раз/с).

## 8. Баланс-ножки

- Вольный луг +12% стабилизирует Стадо в ранние эпохи; надел b5 по-прежнему
  выключает его — «посев» наделом остаётся наказанием.
- Трофей ×2 с Крысы делает мелкую добычу статусом СТАИ, не ломает кап +36%.
- d17 радикально ценнее в «топочных» выкладках (×1.2 скорость углей), но
  прямое число в экономике шалило вправо — аура ослаблена вдвое.
- Шанс теофании до +42% (медиумы 4 + Хтони на поле + внешние в колоде) —
  культисты получают внятную арку «Хозяйка Нисхождений».
