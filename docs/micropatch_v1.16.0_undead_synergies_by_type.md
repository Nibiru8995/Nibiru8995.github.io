# v1.16.0 — Нежить: синергии по типам + индивидуальные здания

## Синергии 1–3 — для ВСЕЙ нежити
Старое правило «соседи одной подрасы связаны» (v1.14) снято. Теперь связи определяет
КАТЕГОРИЯ карты:

1. Любой **Скованный** ⇄ любой **Несущий волю**.
2. Любой **Несущий волю** ⇄ любой **Скованный** и любой **Некромант**.
3. Любой **Некромант** ⇄ любой **Несущий волю**.

Значение звена — по старшей редкости пары (★3 → 0.6, ★4 → 1.1, ★5 → 1.6);
**×1.25, если в паре есть Скелет**. Подрасы остаются особенностями карт:
Скелеты — крепкие звенья и опора зданий, Призраки — связь через клетку,
Вампиры — Кровоток.

## Правило 4 — Владыки работают как было
- **Владыка Тлена (u10)** — связан с ЛЮБОЙ нежитью (+2.0/с за звено) и усиливает
  всю свою цепь на 25% (золотые линии).
- **Прикованный Страж (u11)** — связывается ТОЛЬКО со зданиями (+2.5/с);
  прикованное здание получает цепь с любой соседней картой и КД вдвое короче.
- **Маяк Мёртвых (u26)** — ко всем Призракам; **Право ночи (u38)** — звенья
  без затухания, цепь ×1.15.

## Правило 5 — здания (пока только для Скелетов) 5.1
- **Кладбище**: связывается ТОЛЬКО со Скованными. Способность: **раз в минуту
  выдаёт ИГРОКУ карту из барабана колоды** (deckQueue — по копии за раз).
  За каждую связь со Скелетом-Скованным КД −10с (минимум 10с).
  **Каждое Кладбище тикает ПО СВОИМ часам** (индивидуальные таймеры на клетках,
  десинхронизация по координатам). ⛓ Прикованное — ДВЕ карты за раз.
  **Барабан пуст → Кладбище превращается в Гору костей** (вне зависимости от колоды).
  Старый призыв u0–u3 по таймеру 12с убран. Аура «+12% нежити в радиусе 2» осталась.
- **Склеп**: связывается ТОЛЬКО с Некромантами. **Радиус 1** (+1 за каждого
  ортососеда-Некроманта-скелета): звенья нежити в радиусе НЕ СЛАБЕЮТ
  (первые 2 звена каждой пары; ⛓ прикованный — 4). ⛓ Прикованный: **радиус ×2**
  после модификатора от Некромантов. Туман зоны рисуется честно (динамический радиус).
- **Гора костей**: связывается ТОЛЬКО со Скованными. Скелеты-Скованные и Несущие
  волю в радиусе 1 **считаются УЛУЧШЕННЫМИ на один X** — отдача как у юнита на
  стопку больше (Скелет ×7 даёт как ×8; учитывается и в звеньях, и в базовом доходе).
  ⛓ Прикованная Гора — «ещё на один X» (итого +2). ЖАТВА и +3% за нежить остались.

## Техническое
- `data/synergies.js`: генератор пар по категориям (thrall⇄bearer, bearer⇄necro)
  вместо подрасового; генератор звений зданий (bl_grave/bl_mound → Скованные,
  bl_crypt → Некроманты, только Скелеты); обновлены подсказки `UNDEAD_SUB_RULE`.
- `data/buildings.js`: `BLD_TIMER.bl_grave = 60`; пул призыва Кладбища убран;
  `buildCryptZone` — динамический радиус; новый `buildMoundBoost()`;
  тик Кладбищ — по-индивидуально (graveCD/graveNeed на grid-item) с превращением в Гору.
- `logic/economy.js`: `INC_CTX.moundBoost` — эффективные стопки в perCell
  (звенья и базовый доход).
- `state.js`/`logic/epochs.js`: `deckQueue` — барабан колоды (копия = экземпляр),
  сохраняется в сейве, старые сейвы мигрируют из runDeck.
- `render/grid_render.js`: бейдж КД Кладбища по своим часам; динамический туман Склепа.
- `data/factions.js`, `data/cards.js`: тексты механики и зданий.
- Кэш-баст и footer → v1.16.0.
