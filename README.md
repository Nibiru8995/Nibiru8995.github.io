### v1.5.5 — «ФИКС ЦЕПЕЙ» (правка собственных косяков v1.5.2–v1.5.4 — без «новых фич») ✅

- **Туман остался только у ЗДАНИЙ — и это не декор:** у Кладбища, Склепа, Обелиска, Вольера, Колодца и пр. зона = настоящий радиус механики (призыв, защита звеньев, ускорение, щит).
